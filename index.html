1 · Ask a seller

How the Buyer decides

  1. Resolve the seller's _ans-badge DNS record (only the domain owner can publish it).
  2. Fetch its entry from the GoDaddy ANS transparency log, and refuse any other log.
  3. Check status is ACTIVE, host and agent ID match, not expired, and the endpoint is the registered one.
  4. Only then send the request. Any failure means refuse.
